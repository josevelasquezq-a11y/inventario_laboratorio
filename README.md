# Sistema de Inventario de Laboratorio

## 1. Descripción

Se va a desarrollar una aplicación para administrar el equipo tecnológico dentro de un laboratorio, la aplicación será desarrollada en Python.

## 2. Objetivo

Administrar el equipo tecnológico que se encuentra en el laboratorio, realizar el inventario.

## 3. Usuarios

Administradores del laboratorio

## 4. Funcionalidades

-Registrar equipos
-Listar equipos
-Buscar equipo
-Modificar estado
-Eliminar equipo 
-Salir

## 5. Información de los equipos

Cada equipo contiene:

-codigo
-nombre
-tipo
-estado
-ubicacion

## 6. Tecnologías

Lenguaje: Python

Almacenamiento: Github

## 7. Estructura del proyecto

1.Crear un repositorio en Github. 

2.En Visual Studio Code escribir dos archivos llamados README.md y AGENTS.md, ambos servirán para estructurar el proyecto y darle instrucciones a la IA al momento de generar código.

3.Se usará Google Antigravity para la generación de código.

4.Se validará el código.


## 8. Ejecución

Después de generar el código con el programa Google Antigravity, se validara para verificar si funciona o no.
